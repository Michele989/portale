# Cose da fare, in ordine

## 1. Database (3 minuti)
Supabase → SQL Editor → incolla TUTTO `supabase/schema.sql` → Run. (Si può rieseguire senza danni.)

## 2. Funzioni del server (2 minuti)
Doppio clic su `INSTALLA_FUNZIONI.bat`. (Anche `INSTALLA_PRECARICA.bat` se te lo chiede.)

## 3. Sito (10 minuti)
Estrai `per_github.zip`. Su GitHub → Add file → Upload files → trascina TUTTO il contenuto → Commit changes.
(Non serve toccare la cartella `.github`.)

## 4. Controlla
- GitHub → Actions → Test → Run workflow: deve diventare verde.
- Sito: Ctrl+F5 (telefono: chiudi e riapri), poi premi «Analizza tutta la lista» una volta per avere i nuovi dati.

## 5. Facoltativo
- Pubblicare su Vercel solo se i test sono verdi.

## 6. Prima di vendere
2FA su Supabase/GitHub/Vercel · parere legale su Termini e Privacy · controllo del metodo da uno statistico · licenza di rivendita dati Twelve Data · dominio tuo per le email · COLLAUDO.md su telefono e computer.
